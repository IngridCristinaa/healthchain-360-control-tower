# 🏥 HealthChain 360° — Torre de Controle de Supply Chain Hospitalar

Data Product executivo desenvolvido para monitoramento ponta a ponta da cadeia de suprimentos hospitalares (1.000 SKUs, 50 fornecedores homologados e +3.500 documentos de compra), unindo governança de dados, controle orçamentário e prevenção de ruptura assistencial.

🔗 **Acesse a aplicação ao vivo:** [HealthChain 360° Control Tower](https://ingridcristinaa.github.io/healthchain-360-control-tower/)

---

### 👩‍💻 Desenvolvido por **Ingrid Cristina**
**Especialista de Dados | Business Intelligence | Lean Six Sigma Green Belt**

Projeto desenvolvido sob arquitetura ponta a ponta (*End-to-End Data Product*) com foco em governança de dados, análise de causa raiz (DMAIC) e tomada de decisão executiva, integrando **PostgreSQL (Supabase)**, **Python**, **Power BI / DAX** e visualização web interativa.
